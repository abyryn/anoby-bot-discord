# Command Reference

## 🎵 Music Commands
- `A!play <query/url>` - Play a song or add to queue
- `A!nowplaying` - Show currently playing track with control buttons
- `A!stop` - Stop playback and clear queue
- `A!skip` - Skip current track
- `A!queue` - Show current queue
- `A!pause` - Pause playback
- `A!resume` - Resume playback
- `A!volume <1-100>` - Set volume
- `A!shuffle` - Shuffle queue
- `A!loop` - Toggle loop mode (off/track/queue)

## 🧠 AI Commands
- `A!ask <question>` - Ask a general question (with history)
- `A!image <prompt>` - Generate an image
- `A!clear` - Clear conversation history

## 🎮 Quiz Commands
- `A!quiz [category]` - Start a new quiz session
- `A!quiz stop` - Stop current quiz session
- `A!quiz leaderboard` - Show top players

## ⚙️ System Commands
- `A!ping` - Show bot and API latency
- `A!stats` - Show bot statistics (servers, uptime, memory, etc.)
- `A!help` - Show this list
