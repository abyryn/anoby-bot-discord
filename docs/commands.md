# 📖 Command Reference

## 🎵 Music Commands
- `A!play <query/url/spotify>` - Putar musik dari YouTube, Spotify (Track/Playlist/Album), atau SoundCloud
- `A!nowplaying` - Tampilkan lagu yang sedang diputar dengan tombol kontrol interaktif
- `A!stop` - Hentikan pemutaran musik dan kosongkan antrean
- `A!skip` - Lewati lagu yang sedang diputar
- `A!queue` - Lihat daftar antrean lagu
- `A!pause` - Jeda pemutaran musik
- `A!resume` - Lanjutkan pemutaran musik
- `A!volume <1-100>` - Atur tingkat volume suara
- `A!shuffle` - Acak urutan lagu dalam antrean
- `A!loop` - Ganti mode loop (`off` / `track` / `queue`)
- `A!remove <nomor>` - Hapus lagu dari antrean
- `A!clear` - Hapus semua lagu dalam antrean

## 🎙️ Voice AI Commands (Komunikasi Suara Dua Arah)
- `A!voiceai start` (atau `A!voiceai join`) - Aktifkan bot untuk mendengar mic & menjawab percakapan dengan suara di Voice Channel
- `A!voiceai stop` (atau `A!voiceai leave`) - Nonaktifkan Voice AI & keluar dari Voice Channel
- `A!voiceai voice <gadis|ardi>` - Pilih suara AI (Wanita / Pria berbahasa Indonesia)
- `A!voiceai status` - Cek status aktif Voice AI
- `A!talk <pertanyaan>` - Bertanya ke AI dan dengarkan jawabannya langsung lewat suara di Voice Channel

## 🤖 AI Commands (Teks)
- `A!ai <pertanyaan>` - Chat teks interaktif dengan AnobyStore AI (dilengkapi memori percakapan)
- `A!chat <pertanyaan>` - Alias untuk AI chat
- `A!ai-clear` - Reset memori percakapan Anda dengan AI

## 🎮 Quiz Commands (Kuis AI)
- `A!quiz` - Mulai sesi kuis trivia acak
- `A!quiz <kategori>` - Mulai kuis berdasarkan kategori (contoh: `A!quiz otomotif`, `A!quiz anime`, `A!quiz sejarah`, dll.)
- `A!quiz leaderboard` - Lihat papan peringkat skor tertinggi
- `A!quiz stop` - Hentikan sesi kuis yang sedang berjalan

## ⚙️ System Commands
- `A!ping` - Cek latensi pesan bot dan API Discord
- `A!stats` - Cek statistik performa bot (uptime, memori, server)
- `A!help` - Tampilkan daftar lengkap panduan perintah bot
